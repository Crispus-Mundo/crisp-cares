# CCES Care Portal — source add-ons

Code only. No client, caregiver or health information is ever stored in this repository.
The live app runs as the Google Apps Script project "crisp cares home care client intake"; records stay in the Crisp Cares Google account.

- `ShiftDesk.gs.txt` — Shift Desk server code (availability by text/app, open shifts, matching, first-yes booking, family notice).
- `ShiftDesk-ui.html.txt` — Shift Desk screens added to the care portal.
